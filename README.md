# Python Documentation Parser

Парсер документации Python для сбора информации о версиях, новостях и PEP статусах.

## Описание

Проект предназначен для автоматизированного парсинга официальной документации Python с сайтов:
- https://docs.python.org/3/ - главная документация Python
- https://peps.python.org/ - Python Enhancement Proposals (PEP)

## Функциональность

Парсер поддерживает 4 режима работы:

### 1. **whats-new** - Новости Python
Собирает информацию о новых версиях Python и их основных изменениях:
- Ссылка на статью с новостями
- Заголовок версии
- Описание основных изменений

### 2. **latest-versions** - Последние версии Python
Извлекает информацию о всех доступных версиях Python:
- Ссылка на версию
- Номер версии
- Статус версии (в разработке, стабильная и т.д.)

### 3. **download** - Загрузка документации
Скачивает архив с HTML-документацией Python в формате ZIP файла в папку `downloads/`

### 4. **pep** - Статистика PEP
Анализирует все Python Enhancement Proposals (PEP) и собирает статистику:
- Количество PEP в каждом статусе
- Проверка соответствия статусов
- Логирование несовпадающих статусов
- Итоговое количество обработанных PEP

## Установка

### Требования
- Python 3.7+
- pip

### Шаги установки

```bash
# Клонировать репозиторий
git clone <repository_url>
cd bs4_parser_pep

# Создать виртуальное окружение
python -m venv venv

# Активировать виртуальное окружение
# На Windows:
venv\Scripts\activate
# На Linux/Mac:
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

## Использование

### Базовый синтаксис

```bash
python src/main.py <режим> [опции]
```

### Режимы работы

```bash
# Получить новости Python
python src/main.py whats-new

# Получить список последних версий
python src/main.py latest-versions

# Скачать документацию Python
python src/main.py download

# Получить статистику PEP
python src/main.py pep
```

### Дополнительные опции

- `-c, --clear-cache` - Очистить кеш перед выполнением
- `-o, --output {pretty,file}` - Способ вывода результатов:
  - `pretty` - красивый вывод в виде таблицы (используется `prettytable`)
  - `file` - сохранение результатов в CSV файл в папку `results/`

### Примеры

```bash
# Вывести новости в красивом формате таблицы
python src/main.py whats-new -o pretty

# Получить статистику PEP и сохранить в файл CSV
python src/main.py pep -o file

# Получить список версий с очисткой кеша
python src/main.py latest-versions -c

# Сохранить новости в файл
python src/main.py whats-new -o file
```

## Логирование

Парсер автоматически логирует всю свою деятельность:

- **Консоль** - вывод логов в консоль
- **Файл** - сохранение логов в `src/logs/parser.log`
  - Размер лога: 1MB (10^6 байт)
  - Количество backup файлов: 5
  - RotatingFileHandler обеспечивает автоматическое ротирование логов

Формат логов: `"дата_время - [УРОВЕНЬ] - сообщение"`
